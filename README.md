# RIVIERE

Base visual para una plataforma de catalogo/e-commerce de camisas masculinas premium.

## Fase 1

- Next.js 15 con TypeScript y App Router.
- Tailwind CSS con tokens de diseno sobrios.
- Base shadcn/ui mediante `components.json`, `lib/utils.ts` y `Button`.
- Layout principal con navbar responsive y footer.
- Home editorial con hero, coleccion destacada y valores de marca.
- Rutas futuras preparadas: `/catalogo`, `/producto/[slug]`, `/admin`, `/login`, `/carrito`, `/checkout`.

## Ejecutar

```bash
npm install
npm run dev
```

Luego abrir `http://localhost:3000`.
